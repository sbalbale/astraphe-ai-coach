ASTRAPHE

ASTRAPHE is a Supabase-backed endurance coaching app with a SvelteKit frontend, a FastAPI backend, Redis-assisted rate limiting and caching, and a Google GenAI coaching layer.

This HTML page is a lightweight index. The markdown files in docs/ are the source documentation for implementation details.

Svelte 5
Frontend

SvelteKit 2 SPA/PWA with Capacitor iOS scaffold and Firebase Hosting deploys.

FastAPI
Backend

Python 3.12 API with Supabase Auth, RLS-scoped database access, integrations, and AI orchestration.

Gemma/Gemini
AI

Coach defaults to gemma-4-26b-a4b-it; analysis uses gemini-flash-lite-latest.

Proxmox
Backend Deploy

GitHub Actions builds GHCR images and deploys through Cloudflare Access SSH.

Key Current Behaviors

Auth And Authorization

Protected routes require Supabase JWTs. Tier, admin, model overrides, and AI rate limits come from auth.users.app_metadata.

Coach

POST /v1/coach/message returns JSON. POST /v1/coach/stream is available for SSE clients.

Integrations

Strava, WHOOP, Garmin, Resend, FCM, and Web Push are represented in backend config and docs.

Redis

Redis backs shared sliding-window rate limits and selected workout detail caches. The API falls back to process memory when Redis is unavailable.
